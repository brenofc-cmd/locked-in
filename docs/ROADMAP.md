# Roadmap

Ten stages. Each stage ends only when its behaviour is verified and `docs/PROGRESS.md` is updated.

| #   | Stage                  | Status          | Scope                                                                                                   |
| --- | ---------------------- | --------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | Foundation             | **IN PROGRESS** | Design analysis, Next.js + TS strict + Tailwind, Supabase SDK installed, Vitest + Playwright, docs, git |
| 2   | UI real                | PENDING         | Convert the approved Claude Design (v3) into mobile-first Next.js components with mock data             |
| 3   | Supabase + Auth + Duo  | PENDING         | Schema + RLS, Supabase Auth, profiles, duo invite/join codes                                            |
| 4   | Today + Routine        | PENDING         | Real tasks, recurring routines, check-offs, skip/move, sections                                         |
| 5   | Realtime + Partner     | PENDING         | Partner view live, activity feed, Presence (online/focusing/offline), connection state                  |
| 6   | Focus                  | PENDING         | Focus Mode, timer, sessions, notes, partner sees focusing                                               |
| 7   | Progress + Competition | PENDING         | Streaks, standard, progress stats and charts, weekly comparison, head-to-head                           |
| 8   | Produto completo       | PENDING         | Reactions, challenges, briefing, review day, weekly review, onboarding, settings, history               |
| 9   | QA + Security          | PENDING         | RLS audit, e2e coverage of core loop, accessibility, performance, edge cases                            |
| 10  | Production             | PENDING         | Vercel production deploy, env setup, domain, monitoring                                                 |
